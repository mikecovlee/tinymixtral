# CPT 数学形式化验证账本

本目录是对 CPT 机制数学内容的机器检查证明与准穷举验证。每个脚本独立可跑、
断言失败即非零退出。工具：Z3（SMT 判定）、MPFR/gmpy2（经验证的正确舍入参考）、
NumPy（有限域穷举）。验证环境：z3-solver 5.1.0.0、gmpy2 2.3.2、numpy 2.x、
Python 3.13；采样脚本固定随机种子，逐次运行可复现。

```sh
pip install z3-solver gmpy2 numpy     # 依赖
python cpt_proof/z3_binary_search.py     # L7: FP32 舍入搜索的机器证明
python cpt_proof/z3_lemmas.py            # L2-L5, L8: 代数引理的 SMT 判定
python cpt_proof/bridge_monotonicity.py  # L7 归约桥引理（全 2^31 模式穷举）
python cpt_proof/mpfr_rounding_check.py  # L7/L8: 实现 vs MPFR/精确算术对拍
```

## 归约与假设（诚实声明）

1. **softmax/exp 不直接证明**：超越函数对 SMT 不可判定。L4/L5 将 softmax 归约到
   纯代数恒等式 `yᵢ/Σy`（exp 仅贡献正性），归约本身是定义展开。
2. **一般维数 N**：Z3 证明固定 N（2/3/4/8）实例；任意 N 的通式由相同伸缩/三角
   论证给出（归纳证明属 Lean/Coq 范畴，见方案 Tier 2）。
3. **L7 的 `(t, flag)` 归约**依赖桥引理（已穷举证明）：oracle 比较
   `compare(value(m))≤0` ⇔ `m≤t`，终点中点比较 ⇔ `−flag`。相邻 FP32 值的中点
   永不在网格上（需 25 位尾数），故三分情形无歧义。
4. **L4/L5 是精确算术命题**：零中心化/守恒在实数域成立；FP32 实现保留到舍入
   精度——代码的运行时校验（价格零中心容差 2e-6·scale）恰好界定了该偏差。
5. **实现-证明对应**：Z3 证明针对搜索**算法结构**；`bridge_monotonicity.py`
   与 `mpfr_rounding_check.py` 运行**真实实现**并对照独立参考，防止代码与证明漂移。
6. **不覆盖**：价格环全局收敛速率（top-k 切换的混合系统，研究级）、adaptive
   通道的经验价值——这些是实验命题，形式化方法不替代实验。

## 结果记录

- **L7 定理**（`z3_binary_search.py`）：分解证明三引理全部成立（括号归纳不变式、
  31 步终止界、退出括号=(t,t+1) 且选择=RN-even 且溢出当且仅当越界）；
  单体 31 步符号展开超出求解预算被跳过（设计预期，分解证明已完整）
- **L7 桥**（`bridge_monotonicity.py`）：全 2^31 模式穷举通过（公式=IEEE 视图、
  严格单调、哨兵=2^128、实现=闭式）
- **② 实现对拍**（`mpfr_rounding_check.py`）：336,175 有理数用例 + 22,198 开方
  用例全部一致（含全部指数类边界中点 ties-to-even、溢出边界、MPFR 常规区第三
  方交叉验证）
- **① 代数引理**（`z3_lemmas.py`）：**15 proved / 1 skipped**——L3 步长约束；
  L2 非退化归约链（正值性、恒等式、2D/3D 柯西-施瓦茨、归约恒等式+符号、2D 闭式
  实例）；L4 概率守恒（π 守恒、softmax 归一、top-k 重归一）；L5 价格规范（零中心
  化、softmax 平移不变）；L8 开方 oracle 同序（> 与 =）。跳过项为 3D 闭式实例
  （求解预算耗尽），其结论由已证的归约链+柯西-施瓦茨覆盖
